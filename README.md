# Lo-fi

Lo-fi ищет и воспроизводит музыку из SoundCloud. Один файл bot.js запускает Telegram-бота и веб-сервер Mini App. В нём находятся интерфейс, логотип, авторская графика подборок и схемы SQLite. Сервер использует встроенные модули Node.js 24 и запускается без npm install.

## Быстрый запуск

Нужен Node.js 24 LTS.

    node bot.js

Откройте http://localhost:8080. С пустыми BOT_TOKEN и APP_URL доступен браузерный режим. Поиск и плеер работают с SoundCloud, а медиатека и настройки сохраняются в этом браузере.

## Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather). Впишите токен в BOT_TOKEN в файле .env.
2. Разместите сервер за HTTPS-прокси. В APP_URL укажите корневой публичный адрес, например https://lofi.example.com. Проксируйте весь сайт на порт приложения.
3. В ADMIN_IDS укажите числовые Telegram ID администраторов через запятую. Учитываются ID пользователя, а не @имена.
4. Запустите один экземпляр бота для данного токена. Откройте его личный чат и отправьте /start.

Бот получает обновления через long polling. При запуске он снимает прежний webhook для указанного токена. /start отправляет обложку, текст и единственную кнопку «Открыть Lo-fi». Клиенты с Bot API 8.0 и новее получают запрос на полноэкранный режим, а при ограничении со стороны клиента приложение разворачивает доступную область. Интерфейс учитывает системные и Telegram safe-area отступы. [Документация Telegram Mini Apps](https://core.telegram.org/bots/webapps)

## Docker

    docker build -t lo-fi .
    docker volume create lofi-data
    docker run -d --name lo-fi --restart unless-stopped --env-file .env \
      -p 127.0.0.1:8080:8080 -v lofi-data:/app/data lo-fi

Публикуйте HTTPS через обратный прокси. Если меняете PORT, поменяйте порт контейнера в -p. Контейнер запускается от пользователя node. .env передаётся при запуске. Dockerfile копирует bot.js, а .dockerignore исключает все остальные файлы контекста.

## Управление ботом

Отправьте /admin в личном чате. В панели можно изменить текст, загрузить новое фото, переименовать кнопку, выбрать эмодзи, посмотреть результат или восстановить стандартное оформление. Настройки применяются к следующим сообщениям /start.

Бот получает custom_emoji_id из набора Outline Emoji через getStickerSet. В режиме «авто» выбирает музыкальный эмодзи, если такой есть в наборе. Чтобы выбрать другой, установите набор и отправьте нужный премиум-эмодзи в ответ на запрос панели. Если Telegram отклоняет оформление кнопки, бот повторяет отправку с обычной кнопкой. Поддержка и условия показа эмодзи зависят от Bot API и статуса владельца бота. [Outline Emoji](https://t.me/addemoji/OutlineEmoji) · [Правила InlineKeyboardButton](https://core.telegram.org/bots/api#inlinekeyboardbutton)

## Mini App

- Главная показывает микс и три подборки. Поиск принимает название трека, имя артиста или ссылку SoundCloud. Есть вкладка альбомов, постраничная выдача и фильтр оригиналов. Используются отбор воспроизводимых треков, определение метаданных и устранение дублей из bot (1).js.
- Плеер умеет перематывать, повторять трек, перемешивать и редактировать очередь. Пункт «Открыть в SoundCloud» находится в действиях трека. Для совместимых потоков используется HTML Audio с нативным HLS или Hls.js, для остальных предусмотрен виджет SoundCloud. Доступность зависит от прав на трек и региона. [SoundCloud Widget API](https://developers.soundcloud.com/docs/api/html5-widget)
- В полноэкранном плеере вкладка «Текст» выделяет текущую строку, прокручивает текст и позволяет перейти к строке нажатием. Размер, смещение, размытие и прокрутка настраиваются. Если доступен обычный текст, он отображается без таймкодов. Автоматический поиск текста идёт через LRCLIB по артисту, названию и длительности. [LRCLIB](https://lrclib.net/docs)
- Чтобы добавить свой синхронизированный текст, отправьте боту /lyrics <ссылка SoundCloud или ID трека>, затем пришлите файл .lrc до 64 КБ или текст с метками вида [00:12.34]. Ответ «сброс» удаляет локальный текст.
- В «Настройках» можно выбрать системную, светлую или тёмную тему, настроить непрозрачность, размытие и блики Liquid Glass, включить цветные обложки и настроить поведение плеера. Анимации учитывают prefers-reduced-motion. В некоторых мобильных WebView громкость управляется системными кнопками.

## SQLite и внешние сервисы

data/lofi.sqlite3 в архиве содержит пустую схему. Сервер создаёт файл и таблицы автоматически, если их ещё нет. В базе хранятся настройки стартовой карточки, тексты LRC, настройки пользователей, избранное и история. Для синхронизации Telegram-профиля сервер проверяет подписанные данные initData и срок их действия. Гостевой режим пользуется локальным хранилищем.

В Docker храните /app/data в именованном томе. Для резервной копии можно использовать SQLite .backup либо скопировать каталог базы после остановки экземпляра.

Автообнаружение SC_CLIENT_ID и поиск, перенесённые из исходника, зависят от публичного сайта и внутреннего API SoundCloud. Если автообнаружение изменится, задайте действующий SC_CLIENT_ID в окружении. Исходящие HTTPS-запросы идут к SoundCloud, Telegram и LRCLIB. Для веб-клиента также используются Telegram WebApp SDK и Hls.js. Healthcheck контейнера проверяет HTTP-процесс по /healthz.
